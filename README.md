# FerryLight Blog

> **Real-time ferry tracking, community tech, and a digital lifeline for the North Shore of Nova Scotia**

Documentation, presentation, podcast, and media for **[FerryLight](https://ferrylight.online)** — a community-built system that tracks the **Englishtown ↔ Jersey Cove cable ferry**, local weather, events, marine traffic, and more for residents and visitors on **Cape Breton Island**.

## What is FerryLight?

FerryLight helps people decide whether to wait for the **3–5 minute ferry crossing** or take the **25-minute St. Ann's Loop** when the ferry is down or delayed. It combines **AIS vessel tracking**, a **Progressive Web App (PWA)**, **push notifications**, a **WLED LED matrix display** for at-a-glance status, **Node-RED** automation, and local **weather & events** — all built for a small rural community in **Victoria County, Nova Scotia**.

Perfect if you're searching for: *Englishtown ferry status*, *Jersey Cove ferry wait time*, *Nova Scotia ferry tracker*, *Cape Breton community app*, *AIS ferry tracking*, *DIY IoT weather station*, or *local smart-city projects*.
